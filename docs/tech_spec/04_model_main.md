# 04. 캐릭터 연결 (만든 모델을 Vishamos에 붙이는 방법)

- 작성: 2026-11-25
- 상태: **초안** (사용자 승인 전)
- 근거: 대화 결정 2026-11-25(plan_review 6-1∼6-7), 노션 `[Vishamos-Character]`
- 범위: 모델이 **무엇을 내놓으면** Vishamos가 **어떻게 연결하는지**만 정한다. 캐릭터 디자인·모델링 방식(형태, 폴리곤, 텍스처, 뼈 개수, 어느 표정을 뼈로 할지)은 사용자가 정하며 이 문서에 적지 않는다.
- 사람형 뼈 요구사항은 `03_model_humanoid.md` §1, FBX 내보내기는 03 §4.

항목 구분: `확정` 노션·외부 규약에 명확한 것 / `확정(사용자 답변)` 대화로 정한 것 / `해석` 모호한 부분을 보충한 것(승인 필요) / `보류` 해당 작업 때 정함 / `확인 필요` 결정이 필요한 것 / `AI 제안` 근거가 없는 것(승인 필요)

## 1. 연결 지점

모델은 아래 중 필요한 것만 내놓는다. 없는 것은 건너뛴다(시작할 때 경고 한 줄, 03 3d와 같은 방식).

| # | 모델이 내놓는 것 | Vishamos가 하는 것 | 설정 위치 | 구분 | 근거 |
|---|---|---|---|---|---|
| 1a | **Humanoid Avatar** (03 §1) | Body로 몸·팔·손, Face로 Neck·Head 회전 | `HumanoidCharacter` | 확정(사용자 답변) | 03 1a, 구현됨 |
| 1b | Head 아래에 붙인 것(머리 장식, 뿔, 눈알 등) | 따로 하지 않음. Head와 함께 돈다 | 없음 | 확정 | Unity 계층 |
| 1c | **표정 블렌드셰이프** (이름) | Face 값 → 블렌드셰이프 가중치 | `FaceExpression` 대응표: 대상 이름, Face 값(여러 개면 최대값), `inMin`·`inMax`, `maxWeight` | 확정(사용자 답변) | 03 §3, 구현됨 |
| 1d | **표정 뼈** (뼈 이름 + 값 1일 때의 포즈) | Face 값 0∼1에 따라 쉬는 포즈 ↔ 기록한 포즈 사이를 보간 | 대응표(1c와 같은 형식에 뼈·포즈 칸) | AI 제안 | plan_review 6-6 "표정용 뼈를 많이". Unity는 Blender 드라이버를 가져오지 않으므로 포즈를 값으로 옮김. **코드 미구현(Char-4)** |
| 1e | **머티리얼 값** (셰이더 속성 이름, 예: 동공 UV 이동·크기) | Face 값 → 머티리얼 속성 | 대응표: 렌더러, 속성 이름, Face 값, 범위 | AI 제안 | plan_review 6-2(동공 UV). 속성 이름은 셰이더를 만들 때 정함. **코드 미구현(Char-3)** |
| 1f | **입 모음** A·I·U·E·O (블렌드셰이프, 1d 뼈도 가능) | uLipSync 음소 → 모음 | `FaceExpression` 모음 표 | 확정(사용자 답변) | 03 3c, Char-2 |
| 1g | 흔들림용 추가 뼈(Humanoid에 매핑 안 함) | 흔들림 플러그인이 움직임. 고르기 전에는 고정 | 플러그인 설정, 실행 순서 03 2c | 확정(사용자 답변) | plan_review 6-3 |

- 1c·1d·1e는 한 모델에서 섞어 쓸 수 있다. 어느 표정을 어느 방식으로 할지는 모델이 정한다.
- Face 값의 왼쪽/오른쪽은 저장값 기준(거울, 캐릭터 기준)이다(명세 01 4.4h). 외눈처럼 한쪽만 쓰는 모델은 대응표에서 한쪽 값만 연결한다.
- 어떤 Face 값을 쓸지는 실측(Data-4)을 보고 모델 쪽에서 정한다. 측정값은 `inMin`·`inMax` 보정(plan_review 4-2)에도 쓴다.

## 3. 확인 방법

| 상황 | 기대 결과 | 근거 |
|---|---|---|
| 새 모델 프리팹으로 플레이 | 없는 연결 지점은 경고 한 줄씩, 에러 없이 동작 | §1 |
| 고개 돌리기 | Head 아래에 붙인 것이 함께 돎 | 1b |
| 표정 뼈 채널에 Face 값 0 / 1 (Char-4 후) | 쉬는 포즈 / Blender에서 기록한 포즈와 같음 | 1d |
| 시선 옮기기 (Char-3 후) | 머티리얼 속성이 바뀌어 동공이 움직임 | 1e |
| Unity·OBS·VishasBody 동시 실행 | **60fps**(측정값을 이 칸에 적음) | plan_review 6-7 |
