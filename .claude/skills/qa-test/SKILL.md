# Vishamos qa 도구

## 1. 자동 테스트
- **현재 없음.** Unity Test Framework(`com.unity.test-framework`)가 설치되어 있지 않고, 테스트 실행(`-batchmode -runTests`)은 Unity 에디터가 같은 프로젝트를 열고 있으면 돌지 않는다.
- 그래서 지금 qa는 **구조 검토 + 사용자 시나리오**로 판정하고, 자동 테스트는 "도구 없음"으로 보고한다. 컴파일 확인은 `simple-test`.
- 도입하려면 사용자가 패키지를 추가하고 이 절에 위치(`Assets/Tests/EditMode/`)·asmdef·실행 명령을 적는다.

## 2. 사용자 시나리오 로그
- **위치:** `Logs/scenario.log` (프로젝트 루트 기준. `.gitignore`의 `/[Ll]ogs/`로 제외됨)
- **비우는 법(사용자, 실행 전):** 파일을 지우거나 빈 파일로 만든다. 코드가 없으면 새로 만든다.
- **형식:** 한 줄에 한 이벤트 `[HH:mm:ss.fff] <event> [key=value …]`, 이벤트 이름은 영어 `snake_case`.
- 파일에만 쓴다. 화면·Console에 내보내지 않는다. 서버 주소·받은 바이너리·개인 정보를 남기지 않는다.
- 로그를 남기는 코드: **아직 없음**(worklist `QA-1`). 그 전까지 시나리오는 "로그 지점 대기"로 보고한다.

## 3. 가짜 입력
- Synapse·Body·Face 연결이 필요한 시나리오는 실제 앱을 띄워야 하므로 "프로젝트 사이 확인 순서표"로 사용자에게 넘긴다.
